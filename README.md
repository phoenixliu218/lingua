# Lingua

Personal Brazilian Portuguese + Spanish learning PWA for Phoenix.

Live: https://phoenixliu218.github.io/lingua/

## Sections

- **Lessons** — Themed scenarios (Feira market, Café, Uber, Airbnb host, etc.). Each lesson has 5 tabs: Dialog, Vocab, Grammar, Culture, Practice.
- **Picture Words** — Visual vocabulary by category (Fruits, Vegetables, Meats, Seafood, Market objects, Kitchen).
- **Numbers** — 1 to 1000, ordinals, dates, prices, phone digits.
- **Vocabulary** — Personal saved words & phrases (added from lessons via ⭐).

## Tech

- Vanilla JS / CSS / HTML — no build step
- PWA: service worker + manifest, offline-ready
- TTS audio: Google Cloud Chirp3 HD (Aoede voice) for PT/ES
- Images: Pexels API + Wikimedia Commons (CC-BY-SA)

## Languages

Default focus: 🇧🇷 Brazilian Portuguese with 🇪🇸 Spanish as scaffold and English as gloss.  
After 3 months: switch focus to Spanish (B2 target), with Portuguese retained as scaffold.
